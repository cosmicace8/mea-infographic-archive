Modeling human enterovirus A71 infection using an intestinal microphysiological system.

著者

Futatsusako H, Deguchi S, Kosugi K, Hashimoto R, Nagata N, Suzuki T, Yamamoto T, Takayama K.

掲載元

日本語要約

本論文は、ヒトエンテロウイルスA71（EV-A71）感染のメカニズムを解明するため、腸管マイクロ生理学的システム（通称「organ-on-a-chip」技術）を用いた研究です。この先進的なモデルシステムを活用することで、生体内の腸管環境を模倣し、EV-A71の感染動態や病態生理を詳細に解析しています。本研究は、EV-A71感染症に対する新たな治療法や抗ウイルス薬の開発に貢献する可能性を秘めています。
